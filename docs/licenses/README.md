# Agent skill licenses

The installed skills under `.agents/skills` come from the sources recorded in
`skills-lock.json`. The `untangle-codebase` skill is from
[caldoai/skills](https://github.com/caldoai/skills) and is covered by
[caldoai-skills.txt](caldoai-skills.txt). The other installed skills are from
[jakubkrehel/skills](https://github.com/jakubkrehel/skills) and are covered by
[jakubkrehel-skills.txt](jakubkrehel-skills.txt).
